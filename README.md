# OPON

**Open-source Productivity & Knowledge Management**

OPON is an open-source, cross-platform productivity and knowledge management system designed to bring notes, tasks, projects, and personal knowledge together in one place.

## Vision

Build a lightweight, customizable application that works across desktop and Android, with offline support and seamless synchronization.

## Planned Features

- Notes and document management
- Task and project management
- Customizable themes
- Offline-first storage
- Cross-device synchronization
- Android home-screen widgets

## Technology

- Rust
- Slint
- SQLite
- Axum (planned backend)

## Project Status

🚧 Early development — currently setting up the project and architecture.
